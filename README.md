# ArchonChatBot v1

Production-ready Telegram AI companion bot.

## Features

- AI Chat (DM + Groups)
- Mention / Reply / Greeting triggers
- Multilingual auto-switch
- Conversation context
- Persistent memory
- Voice STT + TTS
- Owner / Sudo / Permissions
- Maintenance mode
- Logger group
- Broadcast system
- Docker support
- Render deployment
- GitHub Actions CI

## Setup

1. Create `.env` from `.env.example`
2. Fill `BOT_TOKEN`
3. Fill `OPENAI_API_KEY`
4. Fill `OWNER_ID`
